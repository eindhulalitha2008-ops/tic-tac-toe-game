# tic-tac-toe-game
A simple and functional two-player Tic-Tac-Toe game built using HTML, CSS and JavaScript.
In this game, two people compete against each other using either 'X' or 'O'. Players take turns selecting gets unoccupied position on a 3X3 grid. The first player to align three of their symbols in a row, column or diagonal wins the game. 

How to play?
1. Make sure the game board is empty before starting. If it is not empty, click "Restart game".
2. There are two players:
  Player 1 uses X
  Player 2 uses O
3. Player X gets the first turn and selects any unoccupied cell on the grid.
4. Player O then selects an unoccupied cell.
5.Players continue taking turns until:
  1. One player aligns three symbols in a row, column, or diagonal and wins, or
  2. All cells are occupied and the game ends in a draw.
6. After each round, the scoreboard keeps track of the wins and draws.
7. Click "Reset Score" to reset the scoreboard completely.
